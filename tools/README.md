# tools —— 可复跑的实测脚本

> 这里的脚本是**用来证伪假设的**,不是"演示能跑"。
> 每一个都记录了一个**我们踩过、且不想再踩**的结论。

| 脚本 | 回答什么问题 | 结论 |
|---|---|---|
| `exp-fp16-memory.py` | fp16 权重在 ORT CPU EP 上省不省内存? | ❌ **反而多 92MB**(CPU EP 加载时转 fp32 ⇒ 双份) |

## 为什么要把"失败的实验"也留下来

**因为一个被证伪的假设,如果不写下【怎么证的】,下一个人还会再试一次。**

- `fp16` 这个结论,**我先前的判断是错的**(我以为"ORT CPU 不支持 fp16")。
  真相是:**支持,但加载时会转 fp32 ⇒ 两套并存 ⇒ 内存不升反降不了**。
  这两个说法差的正是那个实验的价值 —— 所以实验必须可复跑。

## 复跑

```bash
# onnx 若装不上(权限):
pip install --target /tmp/onnxlib onnx
PYTHONPATH=/tmp/onnxlib python3 exp-fp16-memory.py
```
